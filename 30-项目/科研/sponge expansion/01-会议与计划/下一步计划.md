# Sponge Expansion 下一步计划

## 总体目标

在四个迭代内，把现有概念验证模型升级为“可复现、可标定、可比较、能输出结构建议”的研究工具。

## P0｜两周内：建立可信基线

### 模拟侧

- [ ] 按 [[../00-项目管理/M01-M02仿真复现指南|复现指南]] 从空白模型重建 M01
- [ ] 从通过验收的 M01 派生 M02
- [ ] 固定单位制并建立参数来源表
- [ ] 完成 3 档网格敏感性检查
- [ ] 输出 `ALLKE/ALLIE`、`ALLAE/ALLIE` 随时间曲线
- [ ] 保存最终 `.cae + .inp + .odb + 参数表 + 结果图`

### 实验侧依赖

- [ ] 提供样品几何与自由膨胀倍率（均值、离散性、样本量）
- [ ] 提供干态与完全饱水态单轴拉伸/压缩数据
- [ ] 尽可能补充剪切数据
- [ ] 明确测试温度、吸水时间和材料批次

### 验收

- M01/M02 可由另一人依据笔记独立重建。
- 位移趋势与历史动画一致。
- 能量与网格检查通过。
- 所有定量参数均有来源和单位。

## P1｜第 3–4 周：验证简化模型

- [ ] 建立模型 A：直接使用完全饱水性能
- [ ] 建立模型 B：材料参数随温度代理量线性演化
- [ ] 保持几何、接触、网格与加载一致
- [ ] 对比最终形态、接触压力、反力、能量和计算成本
- [ ] 设定简化判据：关键指标差异若低于预设阈值，则优先模型 A

> [!note] 需要团队确认
> 建议首次将关键指标差异阈值设为 10%，但它必须由研究目的和实验误差共同决定。

## P2｜第 5–8 周：从圆筒转向临床场景

- [ ] 定义 2–3 个代表性不规则创腔几何
- [ ] 将刚性边界替换为可变形软组织等效模型
- [ ] 标定海绵—组织摩擦与接触
- [ ] 建立单颗端部填充和多颗粒填充模型
- [ ] 输出填充率、空隙率、压力均匀性、峰值压力及材料外逸风险

## P3｜第 9–12 周：结构设计与实验闭环

- [ ] 参数化至少三类结构：基础柱体、互锁结构、易取出结构
- [ ] 使用统一工况进行结构筛选
- [ ] 选出 2–3 个候选构型进行制造
- [ ] 设计台架实验验证填充、压力与取出完整性
- [ ] 形成“模型预测—实验验证—模型修正”闭环

## 建议评价指标

| 维度 | 指标 |
|---|---|
| 填充 | 体积填充率、残余空隙率、到达目标填充所需时间 |
| 止血代理 | 平均接触压力、低压区比例、压力维持能力 |
| 安全 | 峰值压力、组织最大应变/应力、材料外逸 |
| 取出 | 最大取出力、结构完整率、残留风险 |
| 稳健性 | 对创腔形状、摩擦、材料模量和膨胀倍率的敏感性 |

## 每两周会议模板

1. 上轮承诺是否完成？
2. 新增了什么证据？
3. 哪个假设被支持或否定？
4. 当前最大阻塞是什么，谁负责解除？
5. 下一轮只保留哪三个最高优先级交付物？
