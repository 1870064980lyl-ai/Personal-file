# M01–M02 仿真复现指南

> [!warning] 先读
> 本指南依据四份 journal 还原：M01/M02 的 `*-2022.jnl` 记录建模与多次试错，升级后的 `.jnl` 记录 Abaqus 2023 打开、运行和后处理。journal 不是清洁脚本，包含删除、重建、失败作业和绝对路径；不要整段直接执行。

## 0. 固定复现环境

1. 使用 **Abaqus/CAE 2023**（journal 标记 build `2022_09_29-02.11.55 183150`）。
2. 新建独立工作目录，避免旧 ODB、LCK 和作业名冲突。
3. 明确单位制。journal 无单位声明；从几何尺寸判断很可能采用 **mm–N–s**，但密度与材料参数必须由原作者确认后才能作定量解释。
4. 每一步保存新版本：
   - `M01_rebuild_v01.cae`
   - `M02_rebuild_v01.cae`
5. 建立参数登记表，至少记录：几何尺寸、密度、Hyperfoam 参数、三个方向膨胀系数、步长、幅值、网格尺寸、接触和输出。

## 1. M01：单颗海绵自由膨胀

### 1.1 几何

1. Part → Create，选择 `3D / Deformable / Solid / Extrusion`。
2. 绘制中心位于原点的圆，最终 journal 使用半径 **4.9**。
3. 拉伸深度设为 **5.0**。
4. 命名为 `Sponge` 或保留 journal 中的 `Part-1`。

### 1.2 材料与截面

1. 建立材料 `Sponge`。
2. journal 初始模型使用 **Hyperfoam**，表中记录为 `(0.1, 10.0, 0.0)`。
3. 建立正交热膨胀：
   - 初始曾设置 `(0.0, 2.19722, 0.0)`；
   - 随后改为 `(0.0, 0.0, 2.19722)`；
   - 这意味着最终意图是仅沿局部/全局第 3 方向膨胀。
4. 指定全局材料方向，stack direction 为 `STACK_3`。
5. 创建 `Homogeneous Solid Section` 并赋给整个海绵。

> [!danger] 参数不能盲信
> journal 中还出现过 `Elastic(200000, 0.3)`、`Density(30.0)` 等试验性修改。它们属于调试轨迹，不应当作最终标定值。第一次复现以“能重现变形趋势”为目标，第二次再替换为实验标定参数。

### 1.3 分析步与加载

1. 最终可运行方案使用 **Dynamic, Explicit**，不是早期失败的 Static General。
2. 创建 `Step-1`，总时间设为 **20**。
3. 创建 Tabular Amplitude `Amp-1`：从 `(0, 0)` 线性增加到 `(20, 1)`。
4. Initial 中给海绵全体赋温度 `0`。
5. Step-1 中给海绵全体赋温度 `1`，引用 `Amp-1`。

### 1.4 边界条件

1. 一端面约束横向位移，journal 后期对应 `u1=0, u2=0, u3=UNSET`。
2. 另一端/基准端用于消除刚体运动；journal 曾使用完全固定，也出现位移边界跨步跳变警告。
3. 复现时优先采用最小约束原则：
   - 基准端轴向位移固定；
   - 选取必要节点限制横向刚体运动；
   - 不额外抑制目标膨胀方向。
4. 提交前检查所有位移边界在 Initial 与 Step-1 间是否连续。

### 1.5 网格

1. 全局种子尺寸 **1.0**，deviation factor `0.1`，minimum size factor `0.1`。
2. journal 早期出现 Standard 单元 `C3D8R/C3D6/C3D4`；最终 Explicit 模型应确认单元库为 **Explicit**。
3. 建议以六面体 `C3D8R` 为主，并记录实际单元数。
4. 做至少三档网格检查：1.5、1.0、0.75；比较最终轴向伸长和能量比。

### 1.6 作业与检查

1. 创建作业 `M01_rebuild_v01`，Dynamic Explicit，先用 1 CPU。
2. 输出至少包含 `U、LE、S、STATUS`，并保存：
   - 动能 `ALLKE`
   - 内能 `ALLIE`
   - 人工应变能 `ALLAE`
3. 验收：
   - 能运行至 `t=20`；
   - 膨胀主要沿第 3 方向；
   - 无明显非目标横向膨胀；
   - `ALLAE/ALLIE` 足够小；
   - 准静态目标下 `ALLKE/ALLIE` 不应长期过大。
4. 与 [[../03-结果/M01-自由膨胀/M01.avi|M01 结果视频]] 对比形态。

## 2. M02：刚性圆筒内受限膨胀

### 2.1 从 M01 派生

1. 复制已通过验收的 M01 模型，而不是从历史 M02 CAE 继续修改。
2. 保留海绵几何、材料、温度幅值、Explicit 步和网格。

### 2.2 刚性圆筒

1. Part → Create，选择 `3D / Analytical rigid / Extrusion`。
2. journal 经过多次草图试错，最终目标为：
   - 内半径约 **6.0**；
   - 轴向长度 **50.0**；
   - 以解析刚体圆柱面约束海绵。
3. 为刚体创建 Reference Point。
4. Assembly 中实例化圆筒与海绵。
5. journal 最终把海绵沿轴向平移 `(0, 0, -20)`；复现时以“海绵位于圆筒内部且不初始穿透”为准，用 Query 检查间隙。

### 2.3 接触

1. 创建接触属性 `Prop-Sponge-Rigid`：
   - Normal behavior：Hard contact；
   - Allow separation：On；
   - Tangential behavior：Frictionless。
2. 在 `Step-1` 创建 General Contact（Explicit）。
3. Included pairs 采用 All with self，并为全局接触指定上述属性。
4. 第一次复现保持无摩擦；之后再用实验或文献给定摩擦系数做敏感性分析。

### 2.4 边界

1. 将刚体 Reference Point 的 `U1/U2/U3/UR1/UR2/UR3` 全部固定。
2. 海绵端部只保留消除刚体运动所需的最小约束。journal 最终还对端部节点施加 `U3=0`。
3. 检查海绵膨胀方向、圆筒轴向和材料第 3 方向完全一致。

### 2.5 输出与验收

1. 作业命名 `M02_rebuild_v01`。
2. 除 M01 输出外，增加：
   - 接触压力 `CPRESS`
   - 接触开闭 `COPEN`
   - 接触力/刚体反力
3. 验收：
   - 作业运行至 `t=20`；
   - 海绵与圆筒无初始过闭合；
   - 接触建立后出现合理的 `CPRESS`；
   - 刚体位置保持不变；
   - 能量与单元畸变可接受。
4. 与 [[../03-结果/M02-受限膨胀/M02.avi|局部动画]] 和 [[../03-结果/M02-受限膨胀/M02_whole.avi|整体动画]] 对比。

## 4. 已知风险与排错顺序

1. **Standard 报错**：journal 明确出现“Hyperfoam 与正交膨胀在 Abaqus/Standard 中不兼容”；改用 Explicit，并确认单元库。
2. **边界跳变警告**：检查 Initial 与 Step-1 中 displacement BC 是否突变。
3. **膨胀方向错误**：检查材料方向与 `Expansion(0,0,2.19722)` 的第 3 方向。
4. **动能过高**：延长加载时间、平滑幅值或调整质量缩放；不要只追求算完。
5. **人工能过高/畸变**：细化网格、检查 hourglass、降低膨胀速率。
6. **接触穿透**：先检查装配位置和初始间隙，再调整接触控制。

> [!note] 可复现边界
> 当前文件缺少最终 `.inp`、材料参数来源和完整 ODB，因此本指南能复现 journal 所表达的建模逻辑；要做到数值逐点一致，还需要补齐最终输入文件、单位制和材料标定记录。
