# Personal file — 仓库使用说明

## 目录约定

| 目录 | 用途 |
|---|---|
| `00-主页` | 首页、总览和导航 |
| `10-收集箱` | 尚未分类的临时内容 |
| `20-任务管理` | 任务系统、清单和说明 |
| `30-项目` | 有明确成果和结束条件的工作 |
| `40-领域` | 长期维护的责任与个人资料 |
| `70-附件` | Obsidian 新增的通用附件 |
| `80-模板` | 可复用笔记模板 |
| `90-归档` | 已结束或待核查的保留内容 |

## 命名建议

- 日期统一使用 `YYYY-MM-DD`
- 项目目录使用清晰主题或编号，不使用月份作为一级目录
- 每个项目入口笔记维护 `status` 与 `next_action`
- 新内容先进入收集箱，整理后再归位

## 特殊文件

`My EndNote Library.enl` 与 `My EndNote Library.Data` 是一组 EndNote 数据库文件，必须保持相邻，因此保留在仓库根目录。
