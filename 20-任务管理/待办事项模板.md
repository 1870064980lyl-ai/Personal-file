# 待办事项模板

使用此模板创建新的待办事项时，请复制以下内容：

```markdown
# 任务名称

## 基本信息

- **创建日期**: YYYY-MM-DD
- **截止日期**: YYYY-MM-DD
- **优先级**: 高/中/低
- **状态**: 待开始/进行中/已完成

## 任务描述

描述这个任务的具体内容和目标。

## 子任务

- [ ] 子任务1
- [ ] 子任务2
- [ ] 子任务3

## 备注

添加任何相关的备注或链接。

---

**标签**: #待办事项 #高优先级
```

## 优先级说明

- **高优先级**: 紧急且重要的任务
- **中优先级**: 重要但不紧急的任务
- **低优先级**: 紧急但不重要的任务

## 状态说明

- **待开始**: 任务已创建但尚未开始
- **进行中**: 任务正在进行中
- **已完成**: 任务已完成
