# 待办事项管理使用指南

## 快速开始

### 1. 安装必要的插件
确保已安装以下插件：
- **Templater** - 用于创建待办事项模板
- **QuickAdd** - 用于快速添加待办事项
- **Calendar** - 用于查看日历和设置日期

### 2. 设置 QuickAdd
1. 打开 Obsidian 设置
2. 进入 QuickAdd 插件设置
3. 点击 "Manage Macros"
4. 添加新的宏，名称为 "新建待办事项"
5. 选择 "Template" 类型
6. 选择模板文件：`待办事项/待办事项模板.md`
7. 设置输出文件夹：`待办事项`

### 3. 创建新的待办事项
- 使用快捷键 `Ctrl+P` 打开命令面板
- 输入 "QuickAdd: 新建待办事项"
- 按照提示填写任务信息

## 待办事项格式

```markdown
# 任务名称

## 基本信息

- **创建日期**: YYYY-MM-DD
- **截止日期**: YYYY-MM-DD
- **优先级**: 高/中/低
- **状态**: 待开始/进行中/已完成

## 任务描述

描述任务的具体内容和目标。

## 子任务

- [ ] 子任务1
- [ ] 子任务2
- [ ] 子任务3

## 备注

添加任何相关的备注或链接。

---

**标签**: #待办事项 #高优先级
```

## 使用技巧

### 1. 设置截止日期
在任务中添加截止日期：
```markdown
- [ ] 任务描述 [due:: YYYY-MM-DD]
```

### 2. 设置优先级
使用标签表示优先级：
- `#高优先级` - 紧急且重要的任务
- `#中优先级` - 重要但不紧急的任务
- `#低优先级` - 紧急但不重要的任务

### 3. 使用日历视图
1. 打开 Calendar 插件
2. 在日历上点击日期
3. 在每日笔记中添加待办事项

### 4. 定期回顾
- 每天查看 Dashboard
- 每周回顾所有待办事项
- 每月清理已完成的任务

### 5. 归档完成的任务
- 定期将已完成的任务移到归档文件夹
- 保持 Dashboard 整洁

## 常见问题

### Q: 如何快速添加待办事项？
A: 使用 QuickAdd 插件，按 `Ctrl+P` 然后输入 "QuickAdd: 新建待办事项"

### Q: 如何查看所有待办事项？
A: 打开 `待办事项/Dashboard.md` 文件

### Q: 如何设置截止日期提醒？
A: 使用 Obsidian 的提醒插件，或在任务中添加 `[due:: YYYY-MM-DD]` 格式

### Q: 如何标记任务完成？
A: 将 `- [ ]` 改为 `- [x]`

### Q: 如何删除待办事项？
A: 直接删除对应的文件或任务条目
