# 快速添加待办事项

## 方法1: 使用模板

1. 打开 Obsidian
2. 按 `Ctrl+P` 打开命令面板
3. 输入 "Templater: Insert Template" 并选择
4. 选择 "待办事项模板"
5. 填写任务信息

## 方法2: 快速添加

直接在任何文件中添加以下格式：

```markdown
- [ ] 任务描述 [due:: YYYY-MM-DD] [priority:: 高/中/低]
```

示例：
```markdown
- [ ] 完成项目报告 [due:: 2026-06-20] [priority:: 高]
- [ ] 回复邮件 [due:: 2026-06-17] [priority:: 低]
- [ ] 准备会议材料 [due:: 2026-06-18] [priority:: 中]
```

## 方法3: 使用 Dataview 查询

在任何笔记中添加以下查询：

```dataview
TASK
WHERE !completed
SORT due ASC
```

## 待办事项管理技巧

### 1. 定期回顾
- 每天查看 Dashboard
- 每周回顾所有待办事项
- 每月清理已完成的任务

### 2. 使用标签
- #待办事项 - 所有待办事项
- #高优先级 - 紧急任务
- #中优先级 - 重要任务
- #低优先级 - 可推迟任务

### 3. 设置提醒
- 使用 Obsidian 的提醒插件
- 设置截止日期提醒
- 创建每日待办事项清单

### 4. 归档完成的任务
- 定期将已完成的任务移到归档文件夹
- 保持 Dashboard 整洁
