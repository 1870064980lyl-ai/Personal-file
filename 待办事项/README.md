# 待办事项管理系统

## 文件夹结构

```
待办事项/
├── Dashboard.md          # 主仪表板，显示所有待办事项
├── 使用指南.md           # 详细使用说明
├── 快速添加待办事项.md   # 快速添加方法
├── 待办事项模板.md       # 模板格式说明
├── 新建待办事项.md       # Templater 模板文件
├── QuickAdd配置.json    # QuickAdd 配置文件
├── 示例待办事项.md       # 示例待办事项
└── [其他待办事项文件]    # 你创建的待办事项
```

## 主要功能

### 1. 仪表板 (Dashboard.md)
- 显示今日待办事项
- 显示本周待办事项
- 显示已完成的任务
- 显示所有待办事项

### 2. 快速创建
- 使用 QuickAdd 插件快速创建待办事项
- 使用 Templater 模板自动填充信息
- 支持自定义优先级和截止日期

### 3. 任务管理
- 支持子任务
- 支持截止日期
- 支持优先级设置
- 支持状态跟踪

## 使用方法

### 创建新待办事项
1. 按 `Ctrl+P` 打开命令面板
2. 输入 "QuickAdd: 新建待办事项"
3. 填写任务信息
4. 保存

### 查看待办事项
1. 打开 `待办事项/Dashboard.md`
2. 查看不同分类的待办事项

### 标记任务完成
1. 打开对应的待办事项文件
2. 将 `- [ ]` 改为 `- [x]`

### 删除待办事项
1. 打开对应的待办事项文件
2. 删除文件或任务条目

## 配置说明

### QuickAdd 配置
- 模板文件：`待办事项/新建待办事项.md`
- 输出文件夹：`待办事项/`
- 支持自定义字段

### Templater 配置
- 模板位置：`待办事项/新建待办事项.md`
- 支持日期、优先级、描述等字段

## 注意事项

1. 确保已安装必要的插件（Templater、QuickAdd、Calendar）
2. 定期备份待办事项文件
3. 保持文件夹结构整洁
4. 使用标签进行分类管理

## 扩展功能

### 1. 安装 Dataview 插件
如果需要更强大的查询功能，可以安装 Dataview 插件：

1. 打开 Obsidian 设置
2. 进入社区插件
3. 搜索 "Dataview"
4. 安装并启用

### 2. 使用 Tasks 插件
Tasks 插件提供更强大的任务管理功能：

1. 打开 Obsidian 设置
2. 进入社区插件
3. 搜索 "Tasks"
4. 安装并启用

### 3. 自定义查询
在 Dashboard.md 中添加 Dataview 查询：

```dataview
TASK
WHERE !completed
SORT due ASC
```

## 故障排除

### 问题：QuickAdd 无法找到模板
**解决方案**：
1. 检查模板文件路径是否正确
2. 重新配置 QuickAdd 设置

### 问题：日期格式不正确
**解决方案**：
1. 确保使用 YYYY-MM-DD 格式
2. 检查日期是否有效

### 问题：优先级标签不显示
**解决方案**：
1. 确保使用正确的标签格式
2. 检查标签是否已创建
